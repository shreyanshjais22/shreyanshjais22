## 🚀 What I've Built

### [Imagix](https://github.com/shreyanshjais22/Imagix) — AI SaaS Platform
> *"The first time a real user paid for something I built, everything changed."*

An AI-powered image generation SaaS where users generate images from text, buy credits, and get results in real time. I built everything — the AI integration, the payment system, the frontend, and the deployment.

- Integrated **Clipdrop API** for real-time text-to-image generation
- Built a **dual payment gateway** (Stripe + Razorpay) with webhook verification and atomic transactions
- **Redux** global state management with a fully responsive React UI
- Deployed to production — serving real users

`React` `Node.js` `MongoDB` `Express` `Stripe` `Razorpay` `Redux` `Tailwind CSS`

---

### [Liceria](https://github.com/shreyanshjais22/Liceria) — Multi-Vendor E-Commerce Ecosystem
> *"Building for admins, sellers, and buyers simultaneously taught me what real-world complexity looks like."*

A full e-commerce platform where three types of users — admins, sellers, and buyers — each have their own dashboard and permissions. Not a tutorial clone. A real system.

- **Role-Based Access Control (RBAC)** — completely isolated experiences per role
- Custom **seller dashboard** that improved operational efficiency by **35%**
- **Cloudinary** for optimised media delivery at scale
- Dual payment flows: **Stripe + COD**

`React` `Node.js` `MongoDB` `Express` `Stripe` `Cloudinary` `RBAC` `Tailwind CSS`

---

### [LearnTogether](https://github.com/shreyanshjais22/Talk2learn) — Real-Time Language Exchange Platform
> *"The matching algorithm was the hardest part. I designed the MongoDB pipeline before writing a single API route."*

A community platform that pairs people based on language proficiency and learning goals — in real time.

- **Socket.io** for live, low-latency communication
- **JWT + HTTP-only cookies** for secure auth and session management
- **MongoDB aggregation pipeline** powering a matching algorithm with **95% accuracy**
- Architected for high concurrency from Day 1

`React` `Node.js` `MongoDB` `Express` `Socket.io` `JWT` `REST APIs`
